## Architecture and responsibility boundaries

IDX-005 follows the existing Clean Architecture boundaries. The indexing domain owns closed,
immutable evidence, entity, relation, unknown-construct, batch, and temporal-snapshot types. The
application layer authorizes parser selection, append-only registration, canonical graph
projection, evidence lineage, replay, and temporal queries through ports. Format parsers, SQLite,
the graph/assertion system, revision lineage, and HTTP remain adapters.

Every parser returns one complete `ArtifactTopologyBatch` for one source-revision context. An empty
batch is an explicit removal observation: it supersedes the source's previous batch in current
snapshots without deleting history. Raw source is bounded to 8 MiB, exists only in the ephemeral
`ArtifactTopologySourceArtifact`, and has no persistence field.

## Production parser registry

The pinned registry has one deterministic owner per supported artifact path:

- dependency manifests: npm `package.json`, Python `pyproject.toml` and requirements files, Go
  modules, and Cargo manifests;
- dependency locks: npm lock v1-v3, pnpm lock v5-v9, uv, Poetry, Cargo, and Go sums;
- container artifacts: Dockerfiles and Docker Compose;
- Kubernetes resources, Kustomize bases/overlays, and digest-only unresolved template evidence;
- Terraform HCL and JSON configuration;
- GitHub Actions, GitLab CI, Azure Pipelines, CircleCI, and Jenkins pipelines;
- environment example/sample/template/schema files; and
- AsyncAPI v2/v3, Avro, and event JSON schemas.

Parsers use bounded UTF-8 decoding, document size/depth/node limits, and reject YAML aliases and
anchors. Malformed input fails closed. Unsupported templates, overlays, or constructs retain only
an authorized source coordinate, line interval, reason, and SHA-256 digest; source fragments are not
copied into unknown-evidence storage. Optional model enrichment is deliberately absent until its
provider, privacy, and evidence policy is governed by the later provider/index-policy stories, so
deterministic evidence can never be silently replaced by a model guess.

## Common topology and secret boundary

All formats emit the same closed entity kinds: package, container image, workload, infrastructure
resource, pipeline, environment reference, message channel, event schema, and service. Relations
are restricted to `DEPENDS_ON`, `DEPLOYED_AS`, `PRODUCES`, and `CONSUMES`. Each observation binds
Brain, Project, Repository, source file, source-revision context, semantic entity, immutable
evidence, path, classification, and observed time.

Environment handling accepts only normalized uppercase names and a closed sensitivity class:
public configuration, sensitive configuration, or secret reference. Values are discarded during
parsing. Domain objects, API DTOs, migration columns, and graph fingerprints provide no raw-value or
open metadata field, preventing later adapters from accidentally persisting a supplied secret.

## Canonical graph, time, and lineage

Entity candidates project through GRA-001 stable entities. Relations propose and activate canonical
GRA-002 assertions with exact artifact/source-span evidence, deterministic extractor identity, and
their declared valid interval. The narrowly scoped evidence rule permits a single immutable source
only for the four IDX-005 deterministic relation predicates; all other automated assertion policy
remains unchanged.

Different source and environment observations remain independent temporal assertions. SQLite reads
the latest complete batch per source at a requested cutoff, so current answers do not duplicate
superseded output while historical cutoffs remain reproducible. Every observation registers an
IDX-002 semantic invalidation dependency, and every assertion registers IDX-003
source-revision/evidence lineage. Projection receipts make relation replay idempotent.

## Durability and local API

Migration `0030_idx005_artifact_topology` creates append-only batches, entity candidates, relation
candidates, digest-only unknown evidence, and assertion projection receipts. Update/delete triggers
protect every ledger. Operation ID, scope fingerprint, principal, and canonical batch digest bind
exact retries; conflicting reuse fails. Downgrade is permitted only when every IDX-005 ledger is
empty.

- `POST /v1/indexing/artifact-topology/extractions` authenticates, resolves current-repository
  authority, validates the idempotency key, decodes bytes in memory, selects exactly one parser, and
  returns a value-free batch receipt.
- `POST /v1/indexing/artifact-topology/queries` authenticates, resolves an explicit selected-project
  scope, and returns authorized latest-per-source observations at the requested cutoff.

Both routes are wired into the production local composition root and deterministic OpenAPI export.
