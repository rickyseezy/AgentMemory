## Architecture and invariants

The domain owns the closed migration lifecycle, projection/finding taxonomy, stable finding identity,
and repair policy. Application handlers authorize the exact action before invoking ports. SQLite,
Neo4j, PF-002, FastAPI, Pydantic, and identity resolution remain outbound/inbound adapters or
composition-root dependencies. The domain and application packages do not import infrastructure.

`GraphMigrationRun` is an immutable snapshot with operation, Brain, migration ID and checksum,
fixed source watermark, bounded batch size, cursor, counters, state, and UTC timestamps. Its closed
states are `running`, `paused`, `validating`, `completed`, and `failed`. The source watermark is
captured before mutation. Each applied Neo4j batch uses `MERGE` into `GraphMigrationShadow`; only
after the graph write returns does SQLite append the next checkpoint. Replaying a batch after a
power loss therefore converges on the same effective shadow identity. Completion is legal only
after the durable cursor reaches the watermark and validation proves that every shadow has the
registered migration checksum.

The SQLite migration installs append-only `graph_migration_snapshots`,
`graph_integrity_findings`, and `graph_integrity_repairs` tables. Constraints close states, actions,
finding kinds, dimensions, digests, counters, and approval combinations. Update/delete triggers
protect evidence, exact operation replay is idempotent, and divergent operation reuse fails. A
downgrade is refused after any GRA-006 evidence exists.

## Integrity validation and repair

The scanner runs one fixed, parameterized, globally bounded Cypher query across Assertions,
relationships, and Embeddings. It returns content-free projection metadata and rejects malformed,
over-limit, or out-of-scope results. The deterministic domain policy emits any applicable finding:

- `unsupported_assertion` when an Assertion has no supporting Evidence;
- `orphan_vector` when an Embedding has no canonical source;
- `orphan_edge` when a relationship has no canonical Assertion;
- `invalid_temporal_range` for invalid valid-time or recorded-time intervals;
- `scope_mismatch` when projection endpoints/canonical state cross scope; and
- `stale_generation` when the projection generation differs from the requested current generation.

Non-destructive repairs never delete canonical history. Unsupported, temporal, and stale-generation
findings create an idempotent `GraphRepairShadow`. Orphan and scope findings add a quarantine marker
to the exact authorized node or relationship. SQLite then appends the repair receipt and a
hash-chained central audit fact in the same transaction.

A destructive request is not a direct delete. It requires an explicit approval ID and the current
principal must hold an active owner/admin grant narrowed to the same Brain, Project, and Repository.
The trusted PF-002 bridge also requires the exact relational migration head, successful SQLite
quick and foreign-key checks, and the release-derived rebuild manifest. It then starts a new
generation-isolated PF-002 graph rebuild named from the finding. The API cannot supply or forge the
internal canonical-rebuild verification result.

## Public interface and security

The production composition root exposes these authenticated operations:

- `POST /graph/integrity/migrations/start` (`StartGraphMigration`);
- `POST /graph/integrity/migrations/run` (`RunGraphMigration`);
- `POST /graph/integrity/validate` (`ValidateGraphIntegrity`); and
- `POST /graph/integrity/repair` (`RepairGraphFinding`).

Every route authenticates before resolving current authority, uses a trusted clock, resolves the
specific `graph.integrity.migrate`, `.validate`, or `.repair` action, and accepts a closed request
DTO. Responses expose only IDs, digests, counters, states, finding types, actions, and timestamps.
Known validation, authorization, conflict, integrity, identity, and dependency failures map to
content-free problem responses; raw Cypher, database errors, projection content, paths, credentials,
and hidden reasoning never cross the boundary.
