ADP-001 establishes one host-neutral, versioned event language for Codex, Claude, Gemini, GLM,
generic wrappers, and future external adapters. The contract does not branch on vendor names. A host
adapter first records a UUIDv7 event ID in its durable native observation, then a typed
`NativeEventTranslator` binds the observation to its immutable `AdapterCapabilityDescriptor`. The
same generated-style Pydantic type and checked-in JSON Schema validate bytes at producer and daemon
boundaries; framework-free domain construction repeats every security-relevant invariant.

## Canonical contract

The closed v1 catalog contains all 36 event families required by PRD Section 4.1: session, prompt,
turn, task/checkpoint, tool success/failure, file lifecycle, command, test, Git/checkout/branch,
context injection, memory feedback/correction, attempt/outcome, artifact/incident/feedback, learning,
evaluation, and procedure lifecycle observations. Every type carries major version `v1` and maps to
one immutable `dataschema` URN.

Every accepted domain event contains:

- CloudEvents `specversion`, UUIDv7 `id`, stable URI `source`, versioned `type`, `subject`, aware UTC
  occurrence time, JSON content type, and exact immutable schema URI;
- claimed Brain, local principal, project, repository, checkout, branch, and commit identity;
- agent host, adapter ID/version/digest, explicit model ID (including literal `unknown`), session,
  task, turn, and subagent provenance;
- correlation UUIDv7, causation UUIDv7 when observable, independent UUIDv7 ordering stream, and an
  unsigned 64-bit sequence when available;
- classification, retention policy, declared capture capabilities/method, capability-manifest
  digest, and native source digest; and
- exactly one canonical inline JSON payload or content-addressed CAS reference plus SHA-256.

Inline data is limited to 64 KiB as required by ADR-005. It must be UTF-8 canonical JSON with sorted
keys, compact separators, no duplicate keys, no non-finite numbers, and no hidden-reasoning field.
Larger authorized content must already be encrypted in CAS and use `dataref`. The original event and
payload objects are frozen. Retry translates the same persisted native observation, retaining the
same UUIDv7, ordering coordinates, bytes, and hash.

The checked-in language-neutral schema is reproducible through:

```shell
uv run python tools/export_agent_event_schema.py --check
```

The exporter fails release verification when the generated type and public schema drift.

## Capability and adapter contracts

`AdapterCapabilityDescriptor.create` canonicalizes an immutable adapter ID/version/digest, schema
major, supported family set, and capture-capability set. Its manifest SHA-256 is derived from canonical
JSON. Construction rejects an adapter that advertises a family without the required evidence
capability. Translation rejects any observation outside that descriptor and writes the exact manifest
digest into every event.

`NativeEventObservation` contains already observed, redacted, typed host facts and the adapter-created
event UUIDv7. `CanonicalNativeEventTranslator` is the reference implementation of the generic
`NativeEventTranslator` port. Certified host adapters may parse different native inputs, but their
output must pass this same domain/schema contract and public conformance corpus. Equivalent
observations expose a stable semantic digest that excludes only adapter-specific source/provenance;
this proves host neutrality without erasing original provenance.

Capture methods are a closed set: `native`, `inferred`, `explicit_tool_only`, `unsupported`, and
`permission_denied`. An emitted event cannot claim an unsupported or permission-denied observation.
Optional host identifiers are explicit nullable fields; unknown observable model identity uses the
literal `unknown`, never a fabricated model.

## Daemon trust boundary

`AgentEventAdmissionHandler` performs no persistence and exposes no database port. In order, it:

1. binds adapter ID, version, binary digest, manifest digest, family, capability, and capture method
   to the daemon-selected descriptor;
2. recalculates inline SHA-256, or reads authorized decrypted CAS bytes and verifies hash and size;
3. obtains an injected aware-UTC ingestion time, preserves the original occurrence time, records
   signed microsecond clock skew, and rejects timestamps more than five minutes in the future; and
4. gives adapter-claimed scope only to `AgentEventScopeResolver`, returning the resolver's
   authoritative identity rather than trusting any claimed Brain/project/repository ID.

ADP-002 may persist only the returned `AdmittedAgentEvent`. This separation makes it structurally
impossible for ADP-001 translation to write unvalidated or adapter-authorized scope.

## Error and privacy behavior

All validation failures contain one or more stable `(field, code)` pairs. Rejected values, payloads,
paths, prompts, adapter exceptions, and secret-like data are never included in exception messages.
Transport validation aggregates independent Pydantic field failures. Domain validation rechecks
cryptographic, canonicalization, time, capability, and immutable payload invariants even if a producer
SDK was bypassed.

## Verification evidence

The ADP-001 suite includes a domain and schema-boundary fixture for every required family, strict JSON
and UUID property fuzzing, impossible/naive time cases, delayed and future clock-skew cases, inline and
CAS hash mismatch, descriptor/capability denial, scope-claim distrust, stable retry identity,
cross-adapter semantic equivalence, schema drift verification, and safe multi-field errors. Clean
Architecture contracts prohibit domain/application imports from Pydantic, FastAPI, databases,
adapters, or other bounded contexts.

Release qualification must retain the exact test, coverage, mutation, type, lint, architecture,
security, schema-reproduction, and distribution-build outputs described by the repository quality
workflow. The implementation record is not a substitute for the hosted release evidence.

The final qualification on 2026-07-20 passed 136 focused and 661 repository tests and measured 97.70%
changed-code line coverage and 98.33% changed-code branch coverage. The ADP-001 critical domain killed 247 of 304
generated mutants (81.25%); the complete critical-domain campaign killed 555 of 658 (84.35%). These
results exceed the mandatory independent 80% line, branch, and mutation thresholds.
