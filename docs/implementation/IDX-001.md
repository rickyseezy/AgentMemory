## Architecture and invariants

The indexing bounded context follows Clean Architecture. Domain entities own identities, spans,
language tiers, parser states, semantic priorities, and provenance selection. Application handlers
own authorization-first orchestration, independent file processing, precise-evidence merge, and
bounded search. Filesystem, native parser, SCIP CLI, SQLite, Pydantic, and language-pack details are
outbound adapters. The domain and application layers do not import those frameworks.

`SourceSnapshot` binds one Brain, Project, Repository, optional commit, working-tree digest, and UTC
capture time. `SourceFile` stores only a canonical repository-relative POSIX path. `FileRevision`
binds the exact content digest and byte length to the parser, grammar revision, effective query-pack
digest, precision tier, parse status, and error count. `CodeSymbol` is stable across revisions;
`SymbolRevision` and `SymbolOccurrence` bind it to exact half-open UTF-8 byte spans and zero-based
line/byte-column coordinates. Every span is verified against the original bytes, including Unicode
and CRLF input. Absolute host paths and raw source text are never persisted.

SQLite tables are append-only. Update/delete triggers protect source snapshots, files, revisions,
symbols, semantic evidence, and parser failures. An operation replay succeeds only when the stored
snapshot, scope fingerprint, and every evidence row are byte-for-byte equivalent. Divergent reuse
fails as a conflict, and each file aggregate is committed in one `BEGIN IMMEDIATE` transaction.
Authorization is revalidated against the current grant and exact Brain–Project–Repository binding
on every read and write. A downgrade is refused after any source snapshot exists.

## Language and evidence pipeline

The release supports the required precise syntax tier for Python 3.10–3.14, JavaScript ES2020–2026,
TypeScript 5/6 (including the distinct TSX grammar), Java 17/21/25, Kotlin 1.9/2.x, Go 1.22–1.26,
and C#/.NET 8–10. Structural syntax support covers Rust 2021/2024, C11/17/23, C++17/20/23,
Ruby 3.2–3.5, PHP 8.2–8.5, Swift 5.10/6, Bash/POSIX, and PowerShell 7. Valid UTF-8 files with an
unknown extension receive an explicit lexical-only result and no fabricated semantic symbols;
binary input receives a visible per-file failure.

The language catalog pins each upstream grammar repository and commit. The release lock also pins
the effective tag-query SHA-256 and language-pack bundle digest for Linux, macOS, and Windows on
x86-64 and ARM64. Docker downloads hash-locked Python wheels during the image build, prefetches the
certified grammar set into a read-only image directory, and performs no first-use runtime download.
Native parsing executes in a small spawn-based process pool. A timeout, worker death, or parser
exception retires the affected worker boundary and produces content-free `parser_crash` evidence;
sibling files continue. Detector failures, descriptor failures, malformed plugin DTOs, and an
oversized artifact supplied by any source adapter likewise become bounded per-file failure records;
no plugin-controlled exception or diagnostic text escapes the file boundary.

Tree-sitter emits definitions, references, calls, imports, and implementation candidates with
syntactic source identity. SCIP 0.9 output is converted from protobuf by an absolute, fixed-argv,
checksum-pinned CLI. The converter accepts the real Go JSON field/enum representation, selects one
canonical relative document, rejects duplicate/unknown/ambiguous fields, and reduces it to the
strict evidence DTO. SCIP definitions, references, imports, and implementation relationships use
stable SCIP symbols at priority 300. Compatible precise evidence is selected over Tree-sitter
priority 100 at query time; all lower-priority rows remain available for provenance and repair.

## Local capture and privacy

`LocalWorkspaceSnapshotSource` receives a trusted absolute mount path only at composition time. It
walks regular files without following symlinks, ignores VCS/build/dependency cache directories,
sorts paths deterministically, compares device/inode and size/mtime around each read, and enforces
file-count, per-file, and total-byte limits. It returns repository-relative paths and exact bytes to
the application in memory. The mount path, excluded data, raw parser errors, stderr, source text,
and SCIP document text never enter canonical storage, logs, or API-safe errors.

### Red-Green-Refactor record

- Red: language-matrix, Unicode/CRLF, syntax-recovery, crash-isolation, SCIP-priority, immutable
  replay, authorization, migration, offline-lock, and workspace-policy tests failed while the
  indexing context and schema did not exist. The final boundary audit added failing tests proving
  detector, descriptor, malformed-output, and oversize failures could abort sibling indexing.
- Green: the smallest complete vertical implementation added the domain model and ports, snapshot
  and SCIP handlers, isolated Tree-sitter and SCIP adapters, append-only SQLite repository and
  migration, safe workspace source, and image-pinned language assets. Each plugin-boundary failure
  is now persisted as content-free file evidence while later files commit.
- Refactor: parser, source, precise-import, and repository concerns were separated behind ports;
  canonical validation moved into immutable domain objects; shared failure construction and
  descriptor validation removed adapter-specific branches from orchestration.
