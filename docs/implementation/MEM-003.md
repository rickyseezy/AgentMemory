## Outcome

Newly consolidated memories are deduplicated automatically before their durable work item is
acknowledged. Exact canonical fingerprints are evaluated before any embedding call. Only an exact
miss invokes the pinned local embedding provider, which returns bounded candidate scores but has no
write authority. `MemoryCompatibilityPolicy` independently requires equal memory class,
conservative subject signature, Brain/project/repository/checkout scope, exact valid-time interval,
polarity, promotion-policy version, compatibility-policy version, classification, and retention.
Semantic similarity must additionally reach 9,000 basis points.

The subject signature is deterministic NFKC/case-folded token normalization with a closed synonym,
stop-word, and negation vocabulary. It deliberately favors false separation. Negation is retained as
a separate polarity coordinate, so “use PostgreSQL” and “do not use PostgreSQL” share a subject but
can never merge. The embedding score therefore narrows search; it never decides identity.

## Atomic merge and lineage

The oldest `(recorded_from,memory_id)` profile is the stable survivor. Merged IDs are sorted and
transition from `active` to `merged` with a closed recorded-time boundary and incremented aggregate
version. The survivor remains active and also increments its version. Compare-and-swap checks bind
every profile version immediately before mutation under SQLite's single writer.

`memory_redirects` retains each source-to-survivor decision, mode, policy, operation, and time.
`memory_merge_evidence` retains every source evidence link separately from immutable MEM-002
creation provenance. This distinction is intentional: a merge adds support but never rewrites who
created either original memory. Prior source IDs remain queryable as historical `merged` memories;
redirect lineage supplies their current active identity.

Every successful mutation atomically writes the canonical operation receipt, redirects, evidence
lineage, `MemoryMerged` graph projection source, outbox message, and hash-chained audit record. A
no-op scan still writes an idempotency receipt. Same-operation concurrency returns the committed
receipt; divergent or stale versions fail with a conflict.

## Clean Architecture and SOLID

- `memory.domain.deduplication` owns normalization, profiles, cosine validation, compatibility,
  exact-first planning, result digests, and commit invariants without framework imports.
- `memory.application.deduplicate_memories` owns authorization-first orchestration and the short
  transaction boundary through segregated read, semantic-candidate, repository, and Unit-of-Work
  ports.
- `SqliteSemanticMemoryCandidateFinder` adapts the pinned embedding capability and SQL candidate
  metadata. `SqliteMemoryDeduplicationRepository` owns canonical persistence and CAS behavior.
- `MemoryConsolidationWorker` composes automatic deduplication without granting either the extractor
  or embedding provider repository access.
